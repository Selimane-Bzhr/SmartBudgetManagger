- SmartBudget Manager:
SmartBudget Manager is a user-friendly Excel application designed to simplify personal finance management, expense categorization, and budget tracking.

- Key Features:
•	Dashboard: Offers a real-time summary of total income, total expenses, monthly balance, and budget status.
•	Transactions Sheet: Allows effortless logging of daily income and expense transactions.
•	Category Control: Manages spending categories (Food, Transport, Rent, Health, Education) and sets budget thresholds.
•	Automated Alerts: Features conditional formatting to warn users when spending exceeds budget limits.

- System Requirements:
•	Microsoft Excel 2016, 2019, 2021, Microsoft 365, or any compatible spreadsheet software.

- Quick Start Guide:
1.	Open SmartBudget_Manager.xlsx in Excel.
2.	Switch to the Transactions worksheet to enter daily spending or income.
3.	Check the Dashboard worksheet to review your monthly financial summary and charts.
